# Insurance-Data-Analysis
# Insurance Data Analysis & Feature Engineering

## 📊 Project Overview

This project focuses on analyzing and preparing an insurance dataset using Python.

The project includes data cleaning, exploratory data analysis, visualization, feature engineering, correlation analysis, and feature selection.

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🧹 Data Cleaning

The dataset was cleaned and prepared by:

- Checking the dataset structure and data types
- Identifying missing values
- Handling zero values where required
- Detecting and handling outliers
- Checking data consistency

## 🔍 Exploratory Data Analysis

Exploratory analysis was performed to understand the distribution and relationships within the data.

The analysis included:

- Distribution analysis
- Histograms
- Categorical variable analysis
- Numerical variable analysis
- Correlation analysis
- Data visualization using Matplotlib and Seaborn

## ⚙️ Feature Engineering

The following preprocessing and feature engineering techniques were performed:

- One-Hot Encoding
- Label Encoding
- Creation and transformation of features
- Correlation analysis
- Feature selection

## 📈 Data Visualization

Visualizations were created using:

- Matplotlib
- Seaborn

Histograms and other visualizations were used to understand data distributions, identify unusual values, and explore relationships between variables.

## 📂 Dataset

The dataset contains insurance-related information such as:

- Age
- Sex
- BMI
- Number of Children
- Smoker
- Region
- Charges
